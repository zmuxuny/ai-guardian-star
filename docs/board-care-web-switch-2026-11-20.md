# 网页关怀模式开关（待上板）

## 使用方式

关怀提醒标题右侧增加小开关。先点“解锁操作”输入管理口令，再自行开启或关闭。成功解锁保持8小时，监护服务重启后仍有效；“锁定操作”只锁定按钮，不改变当前关怀模式。口令只提交给设备，不写入网页源码、浏览器本地存储或仓库。

开关始终显示设备实际模式，不因点击就提前变为开启。切换期间按钮禁用并显示等待；断线时继续查询，失败明确提示。开启沿用现有FastDemo与语音（检测2秒、L0/升级/重复为2/3/5秒），使用隔离配置和数据库、不发云端关怀事件，保留30分钟自动关闭。仍需实际识别与状态满足才触发提醒，不承诺开关开启即播放。

## 权限与后台任务

新增`/api/care-control/unlock`、`status`、`mode`、`lock`。专用管理口令通过私有环境变量`AI_GUARDIAN_CARE_WEB_TOKEN`提供，至少24字符，不复用历史、关怀或人脸接口令牌。未配置时接口503，界面提示管理员配置。

采用HttpOnly、SameSite=Strict、限定路径的HMAC签名会话；HTTPS时附加Secure。所有写操作校验同源Origin，模式请求仅接收布尔enabled，限制解锁尝试，不接受命令或任意路径。原鉴权关怀API不变。当前公网仍为已有HTTP地址，此功能不等同完成HTTPS迁移。

默认私有工作根为`/root/guardian-care-control`，可由可信环境变量`AI_GUARDIAN_CARE_WEB_ROOT`指定。其中`kit`需放置**匹配实际上板文件指纹**的现有验证包解压内容。根目录、操作状态和环境文件由root私有管理。

API先持久保存pending，再通过systemd-run启动独立worker，避免监护服务重启杀掉切换任务。request使用非阻塞文件锁，worker阻塞等待交接，避免启动竞态。worker复用DeviceRun.start_shadow/recover_off，只操作本功能持有的配置；看门狗使用另一个独立systemd单元，避免worker退出导致自动恢复机制消失。完成必须通过实际Probe确认模式、配置与摄像头；瞬时连接错误有限重试，持续失败回退并报告错误。任务超时保留会话所有权，允许后续恢复。
