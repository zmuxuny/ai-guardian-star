# 正式监护网页关怀展示设计

## 范围与位置

沿用公网6001页面现有深色三栏监护台（Operate），在中栏首位增加关怀提醒，保留视频、检测状态、人脸、对讲和系统信息。局部青绿色突出关怀状态，不替换全站设计系统。手机优先显示视频和关怀；中小屏恢复页面滚动，避免现有固定高度裁切内容。

## 完整状态

- 加载：读取关怀状态；off：明确已关闭，不保留旧人员/提醒。
- shadow/live：演示模式/关怀已开启；显示当前入镜的已识别人员、累计时长、提醒正文及本轮次数。
- 暂停：显示计时已暂停；等待识别：提示正脸入镜，不要求唯一人员。
- 连接中断或状态不可用：明确无法取得最新状态，清除旧提醒，自动重试或手动刷新。
- 明确区分提醒已触发与语音已播放；语音仅显示通道可用性，不伪造播放回执。

网页仅查看与刷新，不提供未经授权的模式写操作；打开页面不会启动关怀。

## 数据边界

沿用/api/stats轮询，新增care展示字段；只投影当前有效入镜、已绑定的登记标签，不返回私有person_id/event_id/model_version、令牌、完整登记列表或历史记录。失效画面和推理暂停时沿用原stats清理规则。原鉴权关怀API不变。

初始化失败与合法off分开；live和重启恢复后的提醒取当前状态与既有固定文案，不能依赖仅shadow存在的缓存。

## 本地预览

运行（PowerShell 7，项目根目录）：

```powershell
python3.11 tools/preview_care_web.py --port 15502
```

打开：http://127.0.0.1:15502/?scenario=reminder

顶部可切换已关闭、提醒中、等待识别、计时暂停、连接中断。预览显式标注全部为示例数据；仅监听127.0.0.1，不连接开发板，不显示真实人脸、不播放语音。预览中原有摄像头流请求返回404是刻意隔离，生产页面保持原视频逻辑。
