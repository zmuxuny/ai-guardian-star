| `recording_api.py` | 保留期 24 小时 → **7 天**；筛选类型新增 `stranger`；片段未封装完成时返回 `429 异常视频正在生成`；窗口过期提示改为「请刷新查看近7天异常录像」 |

## 六、已知边界与风险

- 无真机：播放与实时画面的结论全部来自 API 24 模拟器，正式签名包与真机未验（`T-20261025-02`）。
- `/video_feed` 仅 320×240，铺满后约 4 倍放大，画面偏软；要清晰需板端提高推流分辨率。
- 首页「实时画面」「在线」角标与放大按钮在右上角互相覆盖，放大按钮实际点不到；属既有布局问题，本次未改。
- 七天自动清理只验了自动化测试与调度启用，未按自然时间观察满 7 天。
- 进程被强杀时残留的临时 mp4 不会被自动清理（有「清理缓存」入口兜底）。
- 其他接口是否存在同类 release 属性改名问题，未做全量排查。
