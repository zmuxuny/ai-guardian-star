## 本轮改动

- 主页沿用蓝色方案 A，标题压缩为 Logo + 智护星；保留通知、个人资料入口，家中设备入口位于摄像头右上角，内部内容居中。
- 摄像头保持比例随滚动缩小，浮窗可拖动并通过边框调节大小；摔倒、人脸、久坐监测位于摄像头下方。设备未连接时显示真实离线状态。
- 独立白底 Logo 冷启动页至少显示 1.8 秒，与系统启动图标统一为 72vp，并按状态栏/手势栏校正位置。从后台恢复页面不重复显示。
- 记录底栏接入最近 24 小时录像：全部、摔倒、久坐筛选；事件范围为开始前 60 秒至结束后 60 秒，持续事件保留已确认过程。新增服务端持续录制、滚动保留和鉴权回放代码。
- 清理缓存功能及说明更新，清理范围为应用缓存/临时文件，不将账号、健康记录、地址等业务数据作为缓存删除。
- 常用地址支持保存详细地址和设为默认；当前页面移除编辑、删除及坐标输入，保存操作位于表单右上角；已有数据及接口兼容保留。
- AI 使用权限改为云端账号策略，包含开启状态、数据等级、版本冲突处理和客户端/服务器双重检查；相关请求字段加入 Release 混淆保留规则。
- 个人页面去掉重复的历史记录入口，保留底部记录页；保留 `HealthHistory.ets` 供现有代码兼容，不能据文件存在推断有个人页入口。
- 项目内增加 Impeccable 设计技能及相应工具配置。

## 构建与本机配置

- 先遵循 `DEVECO_BUILD.md` 的构建任务；其中旧电脑的绝对路径应替换为接手电脑上的实际路径，不要照搬。
- 最近本机构建使用 DevEco 26.0.0.821、Hvigor 6.26.4；项目 `targetSdkVersion` 和 `compatibleSdkVersion` 保留 6.1.1(24)。具体安装 SDK 以本机检查为准。
- Git 中的 `build-profile.json5` 不携带个人签名材料。签名 HAP 前，在 DevEco 的 Signing Configs 中配置自己的签名，或由材料保管人通过安全渠道提供；签名密码和私钥不得提交。
- 本地签名配置、`local.properties`、构建产物、模拟器截图及 `.tmp/` 排障记录不作为交接源码上传。
- 录像服务使用 Linux 的 `fcntl` 和 FFmpeg，不能直接在 Windows 上按生产环境运行。Linux 部署步骤与回滚见录像专项文档。
