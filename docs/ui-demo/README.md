# 智护星界面样张 · 复刻说明

这个目录是一套可以直接在浏览器里打开的界面样张（HTML + CSS + 原生 JS，没有构建步骤）。
复刻时以这几个 HTML 文件为准，本文只说明“为什么这样做”和“照搬时哪些不能丢”。

## 1. 文件和运行

| 文件 | 内容 | 落地目标 |
|---|---|---|
| `index.html` | 总览入口、色板、改动说明 | 不用复刻 |
| `app.html` | 手机 App 样机（主页、记录、AI 助手、个人） | 鸿蒙工程 `entry` 模块的 ArkTS 页面 |
| `site.html` | 官网首页（立体房间 + 内嵌手机） | 官网静态站 |
| `monitor.html` | 板端监控页（团队调试台） | `src/ascend_board_server.py` 里的 `HTML_CONTENT` |
| `fx.js` | 声音与振动，三个页面共用 | 网页直接用；App 换成系统触感和提示音 |

运行：在仓库根目录执行下面的命令，然后打开 `http://127.0.0.1:8765/`。

```bash
python -m http.server 8765 --bind 127.0.0.1 --directory docs/ui-demo
```

直接双击 HTML 也能看，但官网里内嵌的手机样机需要走 http 才能和外层页面联动。

外部依赖只有两处，都走公共 CDN：Google Fonts（Figtree、JetBrains Mono）和 three.js r128（只有 `site.html` 用）。断网时字体回退到系统字体，立体房间自动隐藏只剩手机。

## 2. 设计方向：家里天气

打开只回答一件事：现在平安吗。老人当前的状态决定整个界面的环境光颜色，手机、官网、房间里的灯同时变。颜色只表示状态，不做装饰。

| 状态 | 键 | 底色 | 环境光三色 | 实色 | 指示色 |
|---|---|---|---|---|---|
| 平安 | `ok` | `#052A1F` | `#17B07C` `#0B7A54` `#7BE0B8` | `#0A5C43` | `#2FD39A` |
| 久坐提醒 | `remind`（板端页叫 `sit`） | `#2E1D00` | `#E89A1C` `#8F5200` `#FFD27A` | `#5C3A00` | `#F2B544` |
| 跌倒 | `fall` | `#330A04` | `#F0492C` `#B4260F` `#FF9C86` | `#8C1D0C` | `#FF4A2E` |

文字墨色 `#10231C`。做法：在根节点写 `data-state="ok|remind|fall"`，CSS 变量随它切换，所有面板、按钮、光斑只读变量。

字体：正文 `"HarmonyOS Sans SC","PingFang SC","Microsoft YaHei",sans-serif`；数字用 Figtree 并开 `tabular-nums`；板端页的终端和数值用 JetBrains Mono。
图标：全部是内联 SVG，线宽 1.8，圆头圆角，不用图标字体。

## 3. 通用配方

**玻璃面板**（类名 `.g`）：半透明白底 + `backdrop-filter: blur(22~26px) saturate(1.7)` + 上沿 1px 内高光 + `::after` 一层跟着指针走的径向高光（位置由 `--lx / --ly` 两个变量给）。压在浅色画面上时改用深色玻璃 `rgba(6,17,13,.6)`，否则字看不清。

**动效曲线**

```css
--ease: cubic-bezier(.16,1,.3,1);   /* 进出场、位移 */
--spring: linear(0,.19 4%,.52 9%,.86 15%,1.06 21%,1.13 26%,1.12 31%,1.04 41%,.99 51%,.99 61%,1);  /* 按压回弹、滑块 */
```

按钮按下 `scale(.96)`，松开用 `--spring` 回弹。所有动画在 `prefers-reduced-motion: reduce` 下关闭。

**声音和振动**（`fx.js`，WebAudio 现场合成，没有音频文件）

| 名称 | 用在 |
|---|---|
| `tap` / `tick` | 普通按下 / 滑块每一格 |
| `on` / `off` | 开关打开 / 关闭 |
| `open` / `close` | 弹层出现 / 收起 |
| `ok` / `remind` / `fall` | 切到平安 / 久坐 / 跌倒 |
| `ring` / `connect` / `hang` | 呼叫 / 接通 / 挂断 |
| `send` | 发出一条消息 |

所有 `button`、`a` 按下自动响 `tap`；元素上写 `data-fx="none"` 表示自己另外发声。开关存在 `localStorage['zhx-sound']`。浏览器规定第一次点击之后才能出声。

## 4. App 样机（`app.html`）

对应鸿蒙 7 的“沉浸光感”：玻璃面板、悬浮底栏、分层景深。

- **环境光**：`.amb` 里三个大模糊光斑，颜色取状态变量，缓慢漂移。
- **主页**：上半屏只有状态词（平安 / 该起来走走了 / 跌倒了）、一句说明、通话和看画面两个主按钮、实时画面小窗；下半屏是今日汇总、逐小时条、近 7 天表。状态词和小窗随指针或手机陀螺仪有轻微视差。
- **悬浮底栏**：胶囊形玻璃条，选中项下面有一块用 `--spring` 滑动的指示块；底栏带折射（SVG `feTurbulence + feDisplacementMap`）。
- **记录页**：按天分组，可按类型筛选；点一条打开玻璃弹层，弹层能向下拖走。弹层里有“下载到手机”“标记已处理”。
- **AI 助手**：先显示“正在整理建议…”，再逐字输出。
- **个人页**：AI 开关（关掉后全 App 的 AI 标签隐藏）、数据保留时长滑块。
- **通话浮层**：接通中 → 计时，带声波和静音。
- **两类页面**：要一眼看状态的页（主页、通话、全屏画面、告警）用深色状态底；要读字、要填的页（记录、AI 助手、个人和它下面的设置页、登录）用暖白底 `#F4F7F5`（类名 `.page.lt`），顶部留一条状态色淡光带。两类页共用同一套圆角、字体、图标、回弹动效和悬浮底栏，所以不割裂。
- **状态胶囊**（`.stc`）：浅色页标题右侧的小胶囊，显示当前状态（家里平安 / 久坐 62 分钟 / 跌倒 · 立即查看），点了回主页；跌倒时变实色并闪点。浅色页上状态色只出现在光带、胶囊和底栏三处。

调试入口：地址后加 `?state=ok|remind|fall`、`?tab=...`、`?embed=1`（去掉手机外壳，给官网内嵌用）。

复刻到 ArkTS 时：状态色放进一个全局可观察对象，各页面读它；玻璃用系统的模糊材质能力实现，不必照搬 CSS；底栏用系统悬浮页签栏。数据全部是示意，接真实接口时字段以现有 App 为准。

## 5. 官网首页（`site.html`）

- **首屏**：左边标题和三个状态按钮；右边是一间能拖动旋转的立体房间，房间前面斜放一台手机（内嵌 `app.html?embed=1`）。
- **联动**：点状态按钮 → 根节点 `data-state` 变 → 整页环境光变色 → 房间里老人换姿势（走动 / 坐沙发 / 倒地）、墙上设备的灯和探测环变色 → 约半秒后手机收到 `postMessage` 跟着变，并弹出通知横幅。
- **立体房间**（three.js）：地板、两面墙、窗、门、地毯、沙发、边桌台灯、绿植、墙上设备、老人（基本几何体拼的）；半球光 + 平行光带阴影 + 一盏状态色点光源；设备到人之间有连线和信号小球。支持拖拽带惯性、方向键、空闲时轻摆，离开视口暂停渲染。
- **往下**：三张状态卡（指针倾斜）、三步流程（线上有光点行进）、功能列表、隐私说明、页脚。滚动时逐块浮现。
- 宽度 980px 以下改成上下堆叠。

文案规则：第三人称介绍产品，不对访客说“你”；不写编造的评价、价格、数据。

## 6. 板端监控页（`monitor.html`）

**定位：团队开发和验证功能用的调试台，不是给家属看的。信息密度优先，下面每一块都不能删。**

三栏布局：左（画面 + 终端）、中（状态与数值）、右（对讲与设备）。1100px 以下变两栏，720px 以下单栏。

| 区块 | 内容 | 元素 id | 来自 `/api/stats` 的字段 |
|---|---|---|---|
| 页头 | Uptime、NPU、Stream、FPS、Camera、MQTT | `uptime` `hd-stream` `hd-fps` | `uptime_seconds` `fps` `camera_connected` `mqtt_connected` |
| 画面 | 视频、`● REC`、`FPS`、`POSE_ENG_V4` 标签 | `fps_tag` | `/video_feed`（MJPEG） |
| 终端 | 时间、`[分类]`、消息；最多 80 行；可暂停滚动、清空 | `logBox` | 前端根据状态变化自己追加 |
| 当前检测状态 | 状态词、检测人数、推理帧率 | `det-status` `det-persons` | `status` `detections` `fps` |
| 数据统计 | 摔倒、久坐、陌生人次数 | `s-fall` `s-sit` `s-stranger` | `fall_count` `sit_count` `stranger_count` |
| 关键点置信度 | 头、肩、髋、膝、踝五条，两位小数 | `kpt-head` … `kpt-ankle` | `keypoint_scores` |
| 人脸识别 | 每人一行：名字、说明、匹配分数 | `face-list` | `faces[]`（`label` `score` `reason` `wait_seconds` `timeout_seconds`） |
| 语音对讲 | 声波、状态、开始/结束、增益、麦克风与远程状态、浏览器权限提示 | `call-status` `vol` `mic-status` `remote-status` | `WS /ws/intercom` |
| 设备状态 | 连续监测时长、累计帧数、平均帧率 | `r-uptime` `r-frames` `r-fps` | `uptime_seconds` `frame_count` `fps` |
| 系统信息 | 硬件、框架、模型、协议、App 平台、视频流 | 无 | 固定文字 |

元素 id 特意沿用现有板端页，方便把新样式直接套到现有脚本上。

相对旧页新增的四处：

1. 页头“演示数据”切换（正常 / 久坐 / 摔倒 / 陌生人）——只为看样张用，落地时删掉。
2. 页头多了 Camera、MQTT 两项，数据接口里本来就有。
3. 置信度条上 0.40 的阈值线；低于阈值变琥珀色的规则和旧页一致。
4. 终端的“暂停滚动”“清空”按钮。

状态异常时画面四周描一圈状态色，状态卡整体染色，统计数字跳一下，并响对应提示音。

落地步骤：把 `monitor.html` 的 `<style>` 和 `<body>` 结构替换进 `HTML_CONTENT`；保留现有脚本里的轮询、MJPEG 读流与重连、对讲 WebSocket；删除样张脚本里的 `tick()`、`setSim()` 和示意画面 SVG，换回 `<img id="videoFeed">`；`fx.js` 的内容内联进去（板子上没有这个静态文件）。现有页面里“摄像头离线”“等待新画面”“推理已暂停”等状态词和人脸的各种等待原因文案照旧保留。

## 7. 注意

- 样张里的人名、时间、次数、置信度全部是示意数据，画面是手绘示意图。
- “已查看 / 已处理”标记、主页逐小时条、近 7 天表是新提出的交互，现有 App 里没有，做之前先定数据从哪来。
- 个人页“数据保留时长”的滑块是示意，可选档位以现有 App 为准。
- 样张没有改动鸿蒙工程、官网和板端的任何代码。
