和现在的界面比，改了什么

  • 重点　主页上半屏只放状态词、通话、看画面，原来的灰卡片和蓝按钮都拿掉。
  • 主题　颜色只表示家里的状态：绿是平安，琥珀是提醒，朱红是跌倒。
  • 操作　通话和看画面固定在拇指位，按钮高 52，列表行高不低于 60。
  • 记录　今天逐小时、近 7 天按类型计数、记录页按天分组并可筛选。

需要知道的

  • 画面是手绘示意，时间、次数、人名都是示意数据。
  • “已查看 / 已处理”标记、主页的逐小时条和近 7 天表是新提出的交互，现有 App 里没有。
  • 声音是浏览器现场合成的，第一次点击后才会响；官网右上角可以关。振动只在手机浏览器上有。
  • 官网的立体房间用到 three.js（从公共 CDN 加载），加载不了时会自动只显示手机。
  • 个人页“数据保留时长”的 1 到 7 天滑动条是示意，实际可选档位以现有 App 为准。
  • 这是 HTML 样张，没有改动鸿蒙工程和线上官网的任何代码。
