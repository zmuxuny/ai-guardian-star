## 真人验收方法

需确认本次出镜人员仅有正脸登记照片；不能用包含侧脸的旧图库证明单正脸能力。不自动删除旧照片或替换现有图库。

1. 已登记人员面对开发板摄像头，手机与手不要遮挡脸；待姓名确认为本人。
2. 依次左转30～45度保持5秒、回正、右转保持5秒，重复3轮。记录真实匹配、tracked、pending和误报分别出现的时间。tracked不等于直接侧脸匹配；pending不算识别成功。
3. 大角度侧脸或遮挡超过10秒时可退回未确认；仅正脸样本不能保证首次以任意大角度出现也能匹配，不承诺90度侧脸识别率。
4. 人员离开，再让另一位未登记人员进入同一位置，验证不会继承旧姓名，且清晰正脸有足够负证据时仍能判陌生人。
5. 两人交叉、短暂遮挡后换人，验证轨迹中断/冲突会清除旧身份。此启发式跟踪仍存在身份交换风险，不能用一次单人转头测试代替多人验证。

本轮禁止通过取消陌生人功能、永久保留姓名或直接降低匹配阈值来冒充识别改善。
