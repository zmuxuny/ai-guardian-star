# 板端复验离线准备

目标：以已部署 AF-01 的 0ca3f38 为基线，提前生成可直接使用的验证包、操作说明和判定证据；本轮不连接设备。

范围：复用 Invoke-BoardValidation.ps1；仅补齐 board_validation.py 的重启验证。业务源码、冻结部署指纹、服务配置保持不变。短重启须在已有 L0=1/L1=2 的活动事件上验证，同事件且两级次数不变；实测间断不足120秒，恢复后仍识别同一测试人员。长停须实际超过120秒并建立新轮。缺证不得PASS。

实施：
1. 新增模拟设备回归，复现 L1变化、缺少时间和恢复身份时的误通过；先失败再修复。
2. 记录停服前、恢复首样本和最终样本的单调时间；按上述边界判定，观察期间异常也不得PASS。
3. 在原兼容Python3.9下验证工具、AF-01和发布回退专项；用Prepare实编译、打包，独立解包核对manifest和测试。
4. 交付中文复验手册：固定新会话、现场确认、短停/真实移动/长停/遮挡及身份波动、自然静默、异常收尾和证据路径。
5. 更新协作记录，选择性本地提交；不push、不部署。已有未提交现场记录留在原工作区。

验收：离线包不含凭据/模型/真实数据库，明确board_contacted=false；设备上线后仍需Probe准入和现场动作，不能将本轮模拟结果标为现场通过。
