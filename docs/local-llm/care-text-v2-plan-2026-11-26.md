# 1.5B文字原型边界与分类耗时修正

用户已授权继续修正已复现的边界及超时问题。本轮基于zy@fb4ebf2独立分支，不自动合并仍开放的PR #31；仅复用其研究结论，不重复带入比较报告或工具。

## 修正内容

- 保留历史 tools/local_care_prototype.py 和旧结果，新增v2模块。按分句识别当前真实求助，剔除引用/练习/控制命令的语境；真实求助优先于正向前缀或其他句中的引述。
- 识别有限但可组合的明确安好、无需帮助、正常活动表达，避免只允许5个整句；疑问、矛盾症状、不确定不能因出现“没事”而确认okay。模型okay仍不能单独确认。
- 对含糊症状的模型needs_help建议要求独立的当前协助线索；没有明确求助依据时回到固定澄清，不把模型猜测当老人明确求助。规则覆盖和弃权必须单独统计。
- 分类模型改成内部JSON字符串H/O/U，严格校验后映射到旧实验intent。复用已有SSE截止、完整结束和回环限制，将最大输出从24减到8 token；不是正式v5字段变更，也不是靠播出首个JSON片段提速。
- 旧30/36条仅作为开发复现样本，不用于宣称新验证通过。开发回归先失败再修正，策略冻结后另造输入/独立标签；不按后续新样本结果调参。
