# 智护星录像代码预处理说明

日期：2026-10-19。目标：提前实现可离线验证的基础模块，连接开发板后再选择真实编码器、接入采集、配置参数和验证。

**本轮没有启用录像，没有注册或启动历史接口，也没有提供可用的真实编码后端。** 新模块默认关闭；现有检测、摄像头、音频、MQTT 服务入口未接入这些模块。不能据此认为已经可以全天录像、手机回放或运行七天。

## 已准备的模块

- `src/guardian_recording_config.py`：默认关闭的配置解析和校验，支持可选 JSON 配置；历史令牌只从独立环境变量读取，不进入配置对象的 `repr`。
- `src/guardian_storage.py`：显式初始化空的受管数据根、身份及路径校验、占用统计、北京时间七个自然日的截止点、索引媒体和元数据过期清理。清理是显式调用，尚未接入服务调度。
- `src/guardian_history.py`：独立 SQLite 录像、事件和缺口索引，参数化查询、短连接、写入协调及片段状态。当前没有事件与录像关联表、完整恢复对账或手机确认保存协议。
- `src/guardian_recording.py`：带帧数和字节上限的队列、不可变帧副本、时间戳交接、后台工作线程和后端契约。没有选择或实现真实编码器，也未接入现有摄像头采集点。
- `src/guardian_history_api.py`：供后续显式注册的 `create_history_router(config, store=None, recorder=None)`；带专用令牌鉴权的状态、录像列表、事件列表和事件详情。媒体下载及截图端点有意保持不可用。

这些模块是后续集成的基础，不构成完整录像产品。新建数据不会自动来自现有检测循环；`HistoryStore.add_event()` 和 `RecordingManager.submit_frame()` 需要后续明确接入。

## 配置与默认行为

不设置环境变量时，`RecordingConfig.from_env()` 返回 `enabled=False`，构造禁用的存储对象或路由不会创建目录和数据库，也不会启动线程或摄像头。

`AI_GUARDIAN_RECORDING_CONFIG` 指向 JSON 文件。初始示例保持关闭：

```json
{
  "enabled": false,
  "data_root": null,
  "storage_quota_bytes": null,
  "min_free_bytes": null,
  "retention_days": 7,
  "timezone": "Asia/Shanghai",
  "segment_seconds": 300,
  "record_fps": 15.0,
  "bitrate_mbps": 1.0,
  "encoder": null
}
```

这些帧率、码率和分段是候选值。实际启用要求明确的绝对数据根、正数存储配额和最低空闲空间；没有隐式系统盘落点。`encoder` 即使填写字符串也不会生成编码后端或自动开始录像。

`AI_GUARDIAN_HISTORY_TOKEN` 为独立历史访问令牌，只通过 `Authorization: Bearer ...` 请求头传输。不要写入 JSON、Git、URL、日志或截图，不复用人脸管理员令牌。后续部署应通过设备的安全配置方式注入足够随机的令牌；远程访问还需 HTTPS 和既有网络方案。

当前保守采用 SQLite `DELETE` journal、`FULL` 同步，不在未知板端版本上默认启用 WAL。上板后再结合真实 SQLite 版本、存储和并发需求决定是否增加经验证的 WAL 配置。

## 离线初始化与索引查询

初始化是明确操作，普通构造函数不会认领未知目录。受管数据根必须为空或已经由本模块正确初始化；父目录必须预先存在。不要对现有录像或系统目录试初始化。

以下代码仅使用自动清理的临时测试目录，创建测试数据库并查询一条人工事件，不录制视频、不执行过期删除：

```python
import sys
import tempfile
import time
from pathlib import Path

# 从仓库根目录执行；不修改现有服务。
sys.path.insert(0, str(Path.cwd() / "src"))
from guardian_recording_config import RecordingConfig
from guardian_storage import initialize_storage
from guardian_history import HistoryStore

with tempfile.TemporaryDirectory() as temporary:
    config = RecordingConfig(
        enabled=True,
        data_root=Path(temporary) / "history-test",
        storage_quota_bytes=64 * 1024 * 1024,
        min_free_bytes=1024,
    )
    initialize_storage(config)
    store = HistoryStore(config)
    try:
        event_id = store.add_event("fall", time.time(), payload={"source": "offline_test"})
        print(store.get_event(event_id))
    finally:
        store.close()
```

上述空间参数仅用于小规模临时测试，不能复制为七天全天录像的生产容量参数。操作真实数据根应等连接开发板、核对挂载和备份之后进行。

## 历史接口契约

路由前缀为 `/api/history`。这些地址当前**未注册到 `ascend_board_server.py`，不能直接访问现有服务获得本功能**。后续由服务生命周期显式创建 store、manager 和 router，再调用 `app.include_router(...)`。

- `GET /status`：必须鉴权。正确凭据下即使禁用也返回 200，`state=disabled`；启用且未配置编码器时是 `encoder_not_configured`，其他准备状态是 `prepared`。`prepared` 只表示配置准备状态，`capture_integrated=false`、`recording_backend_ready=false`，不能解释为正在录像。`store_attached`、`recorder_attached` 也仅表示对象已传入。
- `GET /recordings`：片段索引分页。
- `GET /events`：异常事件分页，可用 `kind` 筛选。
- `GET /events/{event_id}`：事件详情，缺失返回 404；本轮尚不返回已实现的录像关联或截图地址。
- `GET /recordings/{recording_id}/video` 和 `GET /events/{event_id}/snapshot`：鉴权和基础状态检查后固定返回 503 `media_not_implemented`。本轮未开放实际媒体读取，不能用于手机播放或下载。

没有配置历史令牌时统一 503；缺失、错误或非 Bearer 凭据返回 401。数据路由在禁用或没有 store 时返回 503。令牌不接受查询参数，错误响应不回显输入、数据库 SQL 或内部异常。响应按白名单输出，过滤绝对/相对路径、媒体文件名、敏感字段和令牌；这会保守地省略含斜杠的普通描述文字，后续如需展示应定义专用公开字段。

查询参数使用 `start`、`end`（必须带时区的 ISO 8601）、`limit=1..200`、`offset=0..100000`。最大区间 31 天，默认最近 31 天；只传单侧时间时补齐 31 天范围。返回时间统一 UTC。拒绝未知、重复参数和非法区间。数据库使用 UTC Unix 秒并参数化查询；31 天是接口扫描上限，不改变七天保留策略。

稳定录像 ID 和事件 ID 统一为 `[A-Za-z0-9_-]{1,128}`；显式传入的非法 ID 在入库前拒绝，默认事件 ID 仍为 UUID。事件类型 `kind` 是非空且不超过 100 个字符的文本，允许中文、空格等 Unicode 内容；入库和接口筛选共用同一校验规则。即使类型文本包含 SQL 语法，也仅作为绑定参数匹配，不拼接为 SQL，不因包含引号而误判为非法类型。

媒体接口暂不开放，是因为真实下载租约、进程间清理协调和 Range 尚未联调；仅增加 `Accept-Ranges` 不能实现续传。状态仅读取当前解释器安装的 Starlette 版本，返回版本是否具备 Range 的初步条件：旧版为 `unsupported_version`，识别不清为 `unknown`，满足引入版本也只是 `version_capable_unverified`。始终返回 `resume_verified=false` 和 `media_download_enabled=false`，不承诺拖动播放、断点续传或安全兼容性。

Starlette 0.39.0 引入 Range，但版本具备此功能不等于适合直接部署。上板时必须核对对应安全修复、FastAPI 兼容性和真实 200/206/416 行为；本轮没有修改项目依赖或自动升级板端环境。

## 验证等级与当前证据

基础和队列测试见 `tests/test_history_storage.py`、`tests/test_recording.py`；历史接口测试见 `tests/test_history_api.py`。以最终仓库实际测试输出为准，不把测试替身当成可播放 MP4。

本轮接口验证：Windows 上使用真实 FastAPI 0.115.14、Starlette 0.46.2、httpx 0.28.1，通过 ASGI TestClient 和临时 SQLite 完成 15 项测试。基础存储 24 项和接口 15 项合计 39 项通过，包含本次补充的两项存储和两项接口一致性测试。依赖仅安装在系统 TEMP 的独立 target，未修改全局环境或 `requirements-edge.txt`。只证明这一组本机依赖通过，未证明全部允许版本或开发板环境兼容。

测试覆盖：所有路由拒绝错误/缺失凭据，未配置令牌拒绝服务，禁用不写盘；真实 SQLite 查询、分页和时区转换；31 天区间边界、参数校验和注入输入；事件详情和不存在的 ID；路径及令牌不进入响应；SQL/设备路径异常不回传；媒体保持 503 且没有伪造 Range 响应头；版本检测不声称已验证续传。

本机已测解释器为 Python 3.12.14：`C:\Users\Yang\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe`。接口依赖位于 `C:\Users\Yang\AppData\Local\Temp\guardian-history-api-test-deps`，其中 `pydantic_core` 含与安装时解释器 ABI、架构绑定的本地扩展；不能把此 target 混用于系统 Python 3.14 或其他不兼容解释器。TEMP 目录被清理后，需要用匹配解释器重新准备隔离依赖，不能把原测试结果当作新环境的通过证据。

以下是该本机环境的完整 PowerShell 7 复测命令；先打印实际解释器版本，并验证真实依赖和本地扩展可导入，结束时恢复调用前的 `PYTHONPATH`：

```powershell
$historyPython = 'C:\Users\Yang\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe'
$historyDependencyTarget = 'C:\Users\Yang\AppData\Local\Temp\guardian-history-api-test-deps'

try {
    $env:PYTHONPATH = $historyDependencyTarget

    & $historyPython -c "import fastapi, starlette, httpx, pydantic_core; print('FastAPI', fastapi.__version__, 'Starlette', starlette.__version__, 'httpx', httpx.__version__)"
    if ($LASTEXITCODE -ne 0) { throw '接口测试依赖或解释器 ABI 不匹配，停止测试。' }
    & $historyPython -m unittest discover -s 'C:\Users\Yang\Documents\ChatGPT\智护星\tests' -p test_history_api.py -v

    }

```

仅当开发板已经安装匹配依赖，或用户自己的虚拟环境已正确配置这些依赖时，才可从仓库根目录使用下列简写；此简写不是上述 Windows 已测环境的完整复现命令：

```powershell

```

没有 FastAPI/httpx 时接口测试会明确跳过，应先在隔离环境准备依赖，再检查测试输出中没有跳过此模块。标准库层通过不能替代接口层通过。

## 连接开发板后的工作

先核对实际版本、备份代码和数据库、确认挂载与时间同步、测量原功能基线。随后选择真实编码后端并验证时长、画质、时间戳、超时和断电恢复，再从唯一摄像头成功采集入口分流。

之后接入服务生命周期、异常开始/更新/结束、截图和录像关联、启动恢复对账、可信时钟与周期清理、缺口状态、磁盘身份和容量告警。最后开放有租约及经过安全核对的媒体播放/下载接口，验证手机查找、200/206/416、断网重试和离线保存。

还需真实连续 24 小时资源观察及第八个自然日清理验证。本机临时数据库的时间边界测试不等于连续七天录像验证；帧队列替身测试不等于 NPU、摄像头、编码器或手机播放验证。

参考：[FastAPI Bearer 请求头](https://fastapi.tiangolo.com/tutorial/security/first-steps/)、[Starlette FileResponse](https://starlette.dev/responses/#fileresponse)、[Starlette 发行记录](https://starlette.dev/release-notes/)、[Range 已知问题公告](https://github.com/Kludex/starlette/security/advisories/GHSA-7f5h-v6xp-fcq8)。总体设计见[全天录像与七天缓存预案](./全天录像与七天缓存预案.md)。
