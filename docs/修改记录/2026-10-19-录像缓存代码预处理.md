## 行为与限制

禁用配置和普通构造无数据目录创建、数据库初始化、采集线程或录像后台线程副作用。显式初始化只认领空目录或核对已有受管目录；不隐式接管现有媒体，不格式化或清空数据盘。

过期删除只在明确调用、可信时间及受管存储校验下执行，不启动自动调度。按北京时间保留当天和前六天，跨截止边界片段采用保守保留。空间不足时不默认提前覆盖保留期内文件。现阶段仅同进程协调写入和清理；完整跨进程租约、恢复对账和周期调用尚待集成。

API 全部使用 `AI_GUARDIAN_HISTORY_TOKEN` 的 Bearer 请求头鉴权，凭据不接受 URL 参数，不返回内部路径或 SQL 错误。带正确令牌的禁用状态接口可返回健康摘要，禁用的数据路由返回 503。实际媒体端点始终不开放，不以添加响应头冒充 Range/断点续传；状态中的版本判断也不证明板端兼容或安全。

运行数据应位于板端经过核对的专用存储根，默认不放入 Git。令牌、录像、截图和真实人物资料不得进入仓库。配置示例不是生产容量设置。
