# 智护星修改记录

每次修改或优化都在本目录新增一份记录，并与代码一起推送到维护分支 `zy`。记录至少包含：问题与修改原因、影响文件、行为变化、代码提交号、备份、验证结果、待验证事项、部署与回退方法。

本地检查与开发板实测分别记录。尚未接入开发板时明确标记“待开发板验证”，实测后追加日期、运行版本、环境、结果与必要日志摘要；不把历史检查结果当作当前版本验证结果。

## 后续记录格式

文件名使用 `YYYY-MM-DD-修改主题.md`。同一天的不同批次分别记录。提交说明应能指出修改目的；记录引用具体代码提交号，并写明推送分支。开发板验证结果应指向实际运行的提交或文件校验值。

记录不保存管理员令牌、MQTT 密码、SSH 私钥、人脸原图或其他凭据。设备私有配置保存在设备上。
