# 单次交接模板

> 复制到自己的 `STATUS-<agent>.md` 最上方，替换占位内容。
> 目标：对方只读顶部两行就知道状态和下一步；全文不超过 40 行。

```markdown
## 2026-10-25 10:11 · deepseek · T-20261025-01 · 待验证

> 分支：wip/deepseek-20261025 @ abc1234 · 基于：zy@b6b3ec8
> 下一步：Codex 在真机验证播放；我补七天清理观察记录。

### 目标

一句话说明这次要解决什么问题。

### 改动

- `path/to/file.py` — 一句话说明行为变化。
- `path/to/Other.ets` — 一句话说明行为变化。

### 验证

- 运行了什么命令，结果是什么；没有运行就写“未运行”。
- 哪一层级：本地测试 / 模拟器 / 板端 / 真机 / 云端。

### 未验证 / 风险

- 明确列出没做的、可能失败的、需要对方注意的。
- 不把“未验证”写成“通过”。

### 下一步

- 给对方的 1–3 条具体动作，带文件或任务 ID。
- 需要用户拍板的写“待用户确认”。

### 回滚

- `git revert <sha>` 或具体恢复步骤；数据库/设备配置写备份路径，不写密钥。
```

## 写法要求

- 顶部两行必须能独立读懂；不要只写“见下文”。
- 代码只写路径、行号、SHA，不贴大段源码。
- 一个任务一条记录；不要把多个不相关改动混在一条里。
- 不写密钥、token、手机号、人脸、日志原文。
