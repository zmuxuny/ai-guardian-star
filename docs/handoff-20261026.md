## 接手

已有本地工作时先保留自己的改动，再获取 `origin/ysh`。当前在 `ysh` 且工作区干净时，可执行 `git pull --ff-only origin ysh`。其他开发分支按团队约定处理合并，勿覆盖未提交内容。

先读根目录 `AGENTS.md`、`DEVELOPMENT_HANDOVER.md`、`DEVECO_BUILD.md` 及协作任务表。构建文档中的工具绝对路径属于另一台电脑，需替换成本机路径。

个人签名配置、私钥、密码、截图和临时日志保留在原电脑；新电脑应在 DevEco Signing Configs 配置自己的签名。推送代码不会自动更新服务器、开发板或其他人的模拟器。
