# AI Guardian Star

This repository contains the Python edge service for the Ascend board: camera inference, fall and sedentary alerts, face recognition, a browser status page, audio intercom, and MQTT notifications. The HarmonyOS client is maintained separately.

See [README_CN.md](README_CN.md) for the repository map, board setup, service endpoints, and hardware verification requirements. The service requires a compatible CANN/ACL Lite installation and must be validated on the target board.
